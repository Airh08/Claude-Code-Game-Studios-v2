# Project Health

Inspect the project and produce evidence-backed scores only where evidence exists.

Dimensions:

- architecture
- code quality
- test coverage
- performance
- documentation/coherence
- technical debt

For each dimension provide score, evidence, risks, and highest-value next action. Do not fabricate numerical metrics when the project cannot provide them.
