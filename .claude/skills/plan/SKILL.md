# Plan Feature

## Procedure

1. Read the project brain and relevant ADRs.
2. Restate the desired player-facing behavior.
3. Identify affected systems and dependencies.
4. Select the smallest useful specialist team.
5. Define implementation steps in dependency order.
6. Define acceptance criteria and validation steps.
7. Identify risks and unresolved assumptions.
8. Assign a stable story/plan identifier when the work is substantial.

Planning must not modify production code.
